            HOW STORAGE WORKS
            Private by design.
            Local by scope.
            Session only
            Cleared at logout, expiry or restart. Saving a session-only key leaves any remembered key unchanged.
            Remember on this computer
            Uses the supported OS credential store and restores the key after you sign in. Not available on every system.
            Forget saved key
            Removes the saved key and clears it from this account's sessions. It does not revoke the key at OpenAI. Already-started jobs may finish.
            This does not verify OpenAI account ownership. Anyone controlling the shared OS account remains within the local trust boundary.
            
    
            ADMINISTRATION
            Manage access. Not secrets.
            Account controls never expose another person's API keys or private jobs.
            User administration
            Changes revoke the selected account's sessions. Already-started jobs may finish. Password resets and user impersonation are not supported.
